# CSI 4106 Introduction to Artificial Intelligence

## Assignment 2: Mission Interruption Prediction with Classical Models

Assignment 2 uses three instructor-prepared files:

- `asrc_missions_complete.csv` contains the 6,371 labelled missions with complete predictor values.
- `asrc_missions_cleaned.csv` contains the same labelled missions and response, but retains the unavailable predictor values identified during data preparation.
- `asrc_missions_hidden.csv` contains 2,124 independently generated missions. It includes `mission_id` and the predictors, but not the response.

The data directory is available here:

- [github.com/turcotte/csi4106-f26/tree/main/assignments-data/a2](https://github.com/turcotte/csi4106-f26/tree/main/assignments-data/a2)
